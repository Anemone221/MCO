### Claude .MD Document###

The What:
This is going to be a Massive Character Organization Tool for Eve online

This is going to allow people who have an higher than average (10+) character count to help organize their characters in eve online.

This is going to include training data. Account synchronization (which characters go to which toons so you can know if you are training on said account.) Fit Testing that checks how many of your characters can use said fit. Grouping of characters for purposes. Location tracking. Skill plan tracking. Implant Tracking.

The How:

This will be an electron application
It will be written in Typescript
Run E to E tests on the project
This is currently a blank repository
This is going to use the eve online static data from: https://developers.eveonline.com/static-data/tranquility/eve-online-static-data-3351823-yaml.zip
The documentation for said static data is here https://developers.eveonline.com/docs/services/static-data/
We will be using eve online's ESI system. The docs are here: https://github.com/esi/esi-docs
Here is the documentation on rate limiting: https://developers.eveonline.com/docs/services/esi/rate-limiting/
And here is a document on best practices for ESI: https://developers.eveonline.com/docs/services/esi/best-practices/
